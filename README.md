## Overview

LSPD Paperwork HUB is a FiveM-oriented paperwork helper for police roleplay communities that want a cleaner way to manage reports, records, and administrative documents. It uses structured templates and browser-based interaction so staff or players can complete everyday paperwork tasks without stepping outside the web view.

This project is built around lightweight HTML delivery, so it can be opened in a browser with minimal friction while keeping the workflow easy to follow. Its purpose is documentation support rather than gameplay expansion, with updates aimed at clearer forms, practical record handling, and a direct experience for roleplay operations.
